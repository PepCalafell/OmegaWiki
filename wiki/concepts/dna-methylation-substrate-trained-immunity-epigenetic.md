## Definition

The proposition that dynamic DNA methylation changes — not only histone modifications — encode part of the long-term epigenetic memory underlying trained immunity, regulating heterologous cytokine responses after a training stimulus such as BCG.

## Intuition

Most trained-immunity epigenetics has focused on chromatin accessibility and histone marks (H3K4me1/3, H3K27ac). This concept reframes whole-blood DNA methylation as a complementary, durable carrier of innate immune memory: BCG-induced methylation shifts that persist to 90 days and track with enhanced ex vivo cytokine production.

## Formal notation

Memory CpGs = sites with significant T90–T0 methylation change that also associate with the trained-immunity fold change FC = cytokine(T90)/cytokine(T0).

## Variants

- Short-term (transient, T14) vs long-term (persistent, T90) methylation memory — see [[biphasic-short-term-reversible-long-term]]
- Histone-based vs methylation-based encoding of innate memory

## Comparison

Distinct from the "immediate" transcriptional response to BCG; methylation memory is a "late" effect that develops largely after day 14.

## When to use

When interpreting how durable innate immune memory is maintained at the genomic level in humans and which molecular layer carries it.

## Known limitations

Whole-blood methylation masks cell-type-specific signals; association does not establish that methylation is causal for the cytokine phenotype.

## Open problems

Whether methylation memory is maintained within trained cells across cell divisions or reflects shifts in cell composition; how it integrates with histone-mark memory.

## Key papers

- [[long-term-dna-methylation-changes-mediate]] — Qi et al., Genome Biology 2025, longitudinal 300BCG EWAS linking methylation dynamics to heterologous cytokine responses.

## My understanding

Positions DNA methylation alongside histone modification as a substrate of trained immunity, with the paper's strongest case being the long-term (T90) memory CpGs that overlap trained-immunity-associated sites.
