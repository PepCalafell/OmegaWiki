## Statement

More than 1,700 single-cell analysis algorithms had been published as of February 2024, creating an acute need to continually evaluate which method performs best in which context.

## Evidence summary

"the development of new analysis tools... has resulted in over 1,700 published algorithms (as of February 2024)" (p.1035). The number motivates the platform: tool proliferation outpaces any static benchmark's ability to keep recommendations current.

## Conditions and scope

Registry-derived count; the true number of usable, maintained tools is smaller. Used here as a scale argument, not a precise inventory.

## Counter-evidence

None material; the count is a sourced registry figure.

## Linked ideas

Motivates the [[concepts/static-versus-living-benchmark-paradigm]].

## Open questions

What fraction of these 1,700 tools are actively maintained and reproducible.
