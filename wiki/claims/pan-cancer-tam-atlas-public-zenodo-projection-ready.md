## Statement

The 363,315-cell pan-cancer TAM atlas is publicly available as a Seurat object via Zenodo (accession 11222158); the analysis code is on GitHub (alexcoulton/macrophage-atlas; Zenodo doi: 10.5281/zenodo.11221774). The atlas is designed for query-to-reference projection of new scRNAseq datasets.

## Evidence summary

Reported in [[papers/using-pan-cancer-atlas-investigate-tumour]] (Coulton et al., *Nat Commun* 2024, Data availability).

## Conditions and scope

Projection requires Seurat-compatible workflow.
