## Statement

The IREA web portal has been incrementally extended with accelerated graph displays, expanded network analysis capabilities, additional coverage of immunostimulatory agents such as chemokines (beyond the original 86 cytokines), and comprehensive per-function user instructions.

## Evidence summary

Reported in [[papers/immune-dictionary-immune-response-enrichment-analysis]] (Lai, …, Cui; AAI 2025 abstract). Extends the IREA software [[foundations/irea-immune-response-enrichment-analysis-software]] beyond the 2024 *Nature* release.

## Conditions and scope

Software/content updates to the public IREA web portal; chemokine coverage broadens the reference beyond cytokines.

## Counter-evidence

The abstract does not enumerate which chemokines were added or quantify the network-analysis expansion.
